# Lifecycle and Visual Regression Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execute inline in an isolated worktree; do not begin implementation as part of saving this plan.

**Goal:** Catch invisible, clipped, unclickable, or stale modal/showcase UI before declaring it fixed, with meaningful lifecycle tests and a small opt-in visual baseline suite.

**Architecture:** Keep Textual's Pilot as the interaction driver. Separate modal lifecycle tests, showcase geometry tests, and deterministic SVG snapshots so failures identify behavior versus rendering. Production changes are limited to defects demonstrated by these tests; retain fresh modal instances on each open.

**Tech Stack:** Python, pytest, pytest-asyncio, Textual Pilot, optional pytest-textual-snapshot, Poetry 2.4.3, GitHub Actions.

**Spec:** [Extension triage: item 0 acceptance criteria](../../2026-09-19-extension-triage.md#item-0-acceptance-criteria).

## Global Constraints

- Python `>=3.11,<4`; Textual `>=8.2.8,<9`; lxml `>=6.1.3,<7`.
- Core must not depend on Pillow, textual-imageview, Textology, or textual-enhanced.
- Keep strict XML and explicit linked-Python actions; no expression evaluation or embedded Python.
- Preserve unrelated root-checkout changes; implementation uses an isolated worktree.
- Normal pytest remains headless and does not generate screenshots. Snapshot tooling is an optional development dependency and runs only when explicitly requested.
- Use four-space indentation, existing naming conventions, and concise imperative commits. Update CHANGELOG only for demonstrated user-facing fixes.

## Review Focus

1. Anonymous and component-private modal controls: event bindings must disappear on dismissal, even though public ID lookup does not register these widgets (Task 2).
2. Repeated click dismissal, Escape, and reopen: each instance must render, return one result, and restore useful focus (Task 1).
3. Resize with the modal open and long content: actions must remain reachable without allowing the dialog to escape the viewport (Task 3).
4. Duplicate opens and failed pushes: reject ambiguous concurrent instances of the same modal definition and roll back new registrations on synchronous push failure (Task 2).
5. Live timers and animation: frozen snapshot state must be repeatable without adding test flags to production controllers (Task 4).

```python
owned_entries = {id(entry) for entries in bindings.values() for entry in entries}
for message_type in bindings:
    remaining = [entry for entry in self._bindings.get(message_type, ())
                 if id(entry) not in owned_entries]
    if remaining:
        self._bindings[message_type] = remaining
    else:
        self._bindings.pop(message_type, None)
for element_id, widget in widgets.items():
    if self._widgets.get(element_id) is widget:
        self._widgets.pop(element_id)
```
